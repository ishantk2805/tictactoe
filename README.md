# Tic Tac Toe

A clean, browser-based Tic Tac Toe game built with vanilla HTML, CSS, and JavaScript.

## Features

- 🎮 **2-Player mode** — take turns on the same screen
- 🤖 **vs Computer** — unbeatable AI using the Minimax algorithm
- 🏆 **Scoreboard** — tracks wins, losses, and draws across rounds
- ✨ **Winning animation** — highlights the winning cells
- 📱 **No dependencies** — single HTML file, works in any browser

## How to Play

Just open `tictactoe.html` in any browser — no install needed.

```bash
open tictactoe.html
```

## Tech Stack

- HTML5
- CSS3 (Grid, animations, gradients)
- Vanilla JavaScript (Minimax algorithm for AI)
